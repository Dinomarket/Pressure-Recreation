Pressure Recreation

A 2D psychological horror game built from scratch using Python and Pygame.

## About

This 2D horror game is inspired by the game Pressure.
The player explores an underwater environment while managing their
sanity and avoiding dangerous creatures.

I created this project to challenge myself to build a more complex game
from scratch and experiment with atmosphere, game mechanics, and enemy
systems.

## Features

- Top-down exploration
- Multiple rooms and environments
- Enemy encounters
- Sanity system
- Lighting and visual effects
- Heartbeat and audio effects
- Interactive objects
- Enemy AI
- Room transitions
- Custom game UI

## Technologies

- Python
- Pygame
- Tiled
- Git / GitHub

## Development

One of the main goals of this project was to create the game without
following a complete tutorial or template. I designed the game's systems
myself and gradually built them together.

I experimented with different approaches to handling rooms, enemies,
player interactions, and visual effects as the project became more
complex.

## Challenges

One of the biggest challenges was getting multiple game systems to work
together. For example, the player's sanity, lighting effects, enemy
behaviour, and room systems all needed to interact correctly.

I also had to debug problems where changes to one system would
unexpectedly affect another. Working through these problems taught me
how to break larger programming problems into smaller pieces.

## What I Learned

This project helped me improve my understanding of:

- Object-oriented programming
- Game-state management
- Collision detection
- Enemy AI
- Event-driven programming
- Working with external map files
- Debugging larger programs
- Designing systems independently
